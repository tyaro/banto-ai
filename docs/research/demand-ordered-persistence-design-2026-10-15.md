# 店舗特性と順序付き持続性：連続重みを用いる第一設計

2026-10-15 JST。[今回の検討範囲](demand-continuous-persistence-scope-2026-10-15.md)と[Astra設計確認](demand-ordered-persistence-astra-review-2026-10-15.md)に基づく設計。新fit/実データr計算/候補予測/2014再採点/2015参照・再評価は行わない。以下は数式案と人工代数例の契約であり、実データ実行の起動契約ではない。

## 判断と過去方式から変える点

既存の持続/非減速・直前整合はハード条件を増やして対象を少数に絞り、2014で支持不足・全停止・残存窓の再校正幅増加を生んだ。今回も店13除外、3/26回避、上昇率閾値、弱い曜日性の店舗群等を作らない。店舗ごとの曜日差を除いたばらつきと、変化の時間順序を、全店共通式の重みへ反映する。

発行前特性で補正の入力を変え、変換後の係数を元の過小/過大制約の下で学ぶ第一案を検討する。既存係数に後から重みを掛けるだけでは平均制約を維持できない。一方、再学習すれば元の補正幅以下とも限らない。これは別のモデル仕様であり、安全化の証明ではない。

## 設計の変更履歴（実データ適用前）

D0草案はr=s*c*E/(E+V)、c=(Σd)^2/(3Σd²)。3変化が同程度で揃うと大きくなるが、順序不変で最新反転と古い反転を区別できない。またV=0,d=(ε,ε,ε)ならε≠0でr=s、ε=0で0となり原点で不連続。切片にもrを掛けるため軽視できない。Astraの代数的指摘を受け、実データr/性能や人工結果を見る前にD0を第一案から外した。D0は反例として保持し、比較候補へ追加しない。

D1を唯一の第一数式案とする。最新変化a=d3、過去平均変化b=(d1+d2)/2を分け、正の緩和定数τで原点を連続にする。τの実値とproduction encoderは未固定。今回は全人工量をτ単位に変換して性質だけを確認し、τ=1を実需要のパラメータとして採用しない。

## 発行前の入力処理案

origin前56暦日だけのdate/value/available_atを使い、date<origin、仮定next-day available≤origin、固定暦日gridを検査する。許可10店、raw0/null/営業unknown、01-01/12-25休業相当は維持。営業相当の実0を残し、欠測0補完しない。未来日/未可用データはエラーであり、r0に丸めて通過させない。

56日を古い順に4×14暦日blockへ分ける。位置j=0..13の全4日が真の観測かつ非休業相当である共通位置集合Jを使う。日付が14日ずつ離れるため同じjは同じ曜日。block間で同じ曜日構成と支持を揃える。s=|J|/14。J空はr0/理由保存。支持比は信頼確率や独立標本数でない。

過去56日の営業相当観測から全体平均μと曜日平均μ_wを計算し、z_t=(y_t−μ_weekday(t))/μとする。μ0/観測なしはr0で理由保存。Jがあれば該当曜日のμ_wは定義され、μ_w0でもμ>0なら計算できる。全0を小さい正数へ置き換えない。

各block L_b=mean_{j∈J} z_bj、d1=L2−L1,d2=L3−L2,d3=L4−L3。V=mean_{b,j∈J}(z_bj−L_b)^2を「曜日・14日水準を除いた残差energy」と呼ぶ。真のnoise分散と認めず、週内変動・一時変動・trendも残り得る。共通Jにより曜日平均はblock差で相殺するので、曜日調整の役割は主にVにある。

2013全期間profileを2013originへ遡及して渡さない。新重み用のμ/μ_w/Vは各origin前56日だけ。既存の2013尺度uを2014cutoffで用いる遡及学習の正規化と、当時可用なprofileを分ける。2013当時の実予測を再現したとは主張しない。単年の年季節型、月/Q型、店IDは新入力へ加えない。

## 単一の順序付き重み

```
a = d3
b = (d1+d2)/2
r = s * 2*max(a*b,0) / (a*a + b*b + V + τ*τ),  τ>0
```

0≤r≤s≤1。2|ab|≤a²+b²から従う。固定τ>0の下で分母は常に正で、原点を含め連続。同方向でも大きさが揃わない、Vが大きい、共通観測位置が少ないほど抑える。最新と過去平均が逆方向、最新単発、過去変化が相殺してb0、横ばいa=b0ではr0。

rは発行前履歴の規則から作る重みであり、次14日の方向が正しい確率ではない。正しい新しい水準へのstep、良い反転初期、急成長も抑え得る。過去で揃った動きが次期に続く保証もない。τを正にすることで数学的連続性は得られるが、適切なτの実需要尺度や有用性は未検証である。

## 共有学習への組込み案

既存3特徴x=(1,水準差,週変化)をz=r*xへ変える。切片もr倍となり、定数の切片ではなくなる。P=B+14u*zβ、同じ自Q10店共有3係数/λ1（全係数罰則）の正規化MSEを最小化し、自Q過去の平均under/over≤同休業mean28と学習P≥0を直接課す。rがtarget/βによらなければPはβに線形、hingeの凸性とλ1の厳密凸目的を維持する。

元のE（既存特徴が支持される行）のnEを維持し、r0/重み用支持不足でも行をdrop・非ゼロr集合へ再正規化しない。z=0のB固定損失として目的分母に残す。riskは全complete Iを1/(10nI)で、元の入力不支持行も残す。既存特徴不支持/B0もB。r0の理由と、計算可能/非ゼロr/非ゼロ方向/最終変更を別カウントする。

r≤1は同じβを固定した時の補正幅縮小だけを意味する。再fit後のβが変わるので旧最終幅以下とは言えない。λを1に保っても特徴を縮めるため正則化の効き方は変わる。全r0ならB同値という負結果を記録し、成功認定しない。旧3/6/7/5発行日という支持の薄さも解消されない。

## 今回の人工確認と実装前の未決事項

人工例はd/τとV/τ²の無次元座標を使い、a/τ,b/τの分母に+1を置く。これは正規化した式の代数確認で、実需要のτを固定したものではない。横ばい/同方向持続/単発/最新反転/古い反転/過去相殺/加減速/大残差/部分支持の性質を確認し、D0の順序不変・不連続反例、同履歴から相反する将来が可能な反例、事後row別縮小が平均条件を破る反例を残す。実データrや店13/3/26の重みを計算しない。

実装起動前には少なくとも次を別契約で固定する。

1. 全店共通の正τ実値とその選定根拠。既読Q1や特定店を通す値、実データr分布を見た救済gridを使わない。人工τ単位の例を実値選定へ流用しない。
2. μ/μ_w/L/V/rの計算順・数値型・保存/変換丸め・8192bitチェック・encoder/canary・J空/μ0/真0/null/closureの人工境界。今回のscalar代数確認はraw入力処理の統合試験ではない。
3. 自Qprefixへ新しい過去56具体payloadを渡し、未来/label/全履歴を学習関数へ渡さない。全四季の構造支持、非ゼロrの店/発行日数、特徴energy集中とrankを監査し、少数非ゼロを成功支持としない。r0の行削除/再重み付けなし。
4. 候補は一つ、対照は同休業mean28。比較の母数・四季all/normal・元日・年末・observed/assumed分離、四季平均under/over非増加と既存MSE条件、年間厳密改善、既存p192符号規則を先に固定。2014Q開始以前だけでfitし、全260予測を採点前保存。違反Qの事後B差替えなし。
5. 上限/証明/入力/資源failureで停止、負結果/全B/未判定も保存し、λ/τ/式/期間/閾値/分類の再探索をしない。新年度の独立検証とは認めず、2015は停止を維持する。

今回からこの実装契約・real support監査・fitへ自動接続しない。四季平均under/over非増加・同休業mean28・観測/欠測0仮定分離・調整2014以前を維持し、旧方式のQ1不適格も変えない。

## 一次資料と今回の仮説の区別

[時系列特徴量の教科書](https://otexts.com/fpp3/features.html)は変動・差分相関・非重複blockの水準差等を系列記述に用いる方法を説明する。[共有/個別モデルの研究](https://arxiv.org/abs/2008.00444)は、異質な系列でも共有モデルが有効な場合があると論じる。これらは今回のr式やその性能を検証した資料ではない。

[過去だけで学ぶ時系列評価](https://otexts.com/fpp3/toolbox.html)の原則を守っても、既読2014を繰り返し設計へ使った探索性は残る。今回のrはAstraとの検討による未検証仮説であり、予測性能・因果・安定店舗型・未来非悪化・PSI採用を認定しない。
