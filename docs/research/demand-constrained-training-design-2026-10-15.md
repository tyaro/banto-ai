# 四季の両側非増加を学習へ組み込む第一設計

## 問いと第一仕様

仮説は、MSEで先に決めた補正方向を後から縮めるのでなく、過小量・過大量の条件を満たす係数の方向そのものを学べば、同じ3特徴で異なる解を得る余地がある、というもの。非ゼロ可行解や改善解が存在すると主張しない。

第一仕様を一つに限定する。既存の共通3係数、λ=1（切片も罰する）、入力支持、2013尺度、許可prefix、既定mean28と休業仮定を維持し、全pastQの過小量・過大量非増加および学習行の非負を直接制約する。後段のalpha再fitは重ねない。currentQだけの制約、店・季節別係数、soft penalty、λ/特徴/期間探索は追加しない。

Q別MSEは第一仕様の学習hard制約に加えず、既存の正規化MSEを目的に残す。学習目的全体の改善とQごとのMSE非悪化は別である。将来の時系列診断では従来どおりQ別MSE・過小量・過大量の三条件を確認し、違反したQの予測と悪化を保存する。Q別MSE制約の追加は今回の比較候補にせず、結果後の救済にも使わない。

## 入力と重み

各2014Q開始cutoff以前に完結し、仮定available_atを満たす2013–2014の許可10店だけを対象とする。accepted keysではなく、[adapter](../../tools/demand_prefix_adapter.py)による具体的な許可rowのfresh copyだけを学習関数へ渡す。全input/label reader/index/sourcepathは渡さない。これまでのinput/label分離と日単位の仮定時点整合を維持する。2013尺度uは2014cutoffで可用であり、2013当時の予測を再現したとは言わない。

過去観測完全集合をI、特徴適格集合をE、発行四半期qの集合をI_qとする。年をまとめた発行Q別であり、年度×Q別条件は追加しない。過去年ごとの非増加は保証しない。

- 目的用の重みは、E内Q×店cellの件数n^E_qsに対してw_i=1/(4×10×n^E_qs)、和1。従来と同じ全40cell支持を必要とする。
- 制約用の重みは、I_q内の各店件数n^I_qsに対してv_i=1/(10×n^I_qs)、各Q和1。特徴不支持のB固定行も分母に残す。
- B_iは同じ休業仮定mean28の14日総量、Y_iは観測完全な14日販売数量。u_i>0は既定尺度。raw0は観測値、nullは欠測、営業状態unknownは維持する。欠測0仮定を学習targetや制約に入れない。

## 係数を直接制約する二次計画

適格行のx_iは既存の(切片、水準差、週変化)。h_i=14u_i x_i、P_i(β)=B_i+h_iβとする。特徴不支持またはB_i=0はh_i=0としてP_i=B_iに固定する。

最小化する目的は次のとおり。

```
J(β) = Σ[i∈E] w_i ((Y_i−B_i)/(14u_i) − x_iβ)^2 + Σ[j=0..2] β_j^2
```

全学習rowでP_i(β)≥0とし、各q=1,2,3,4について次を同時に課す。

```
Σ[i∈I_q] v_i max(Y_i−P_i(β),0) ≤ Σ[i∈I_q] v_i max(Y_i−B_i,0)
Σ[i∈I_q] v_i max(P_i(β)−Y_i,0) ≤ Σ[i∈I_q] v_i max(B_i−Y_i,0)
```

補助変数a_i≥0、a_i≥Y_i−P_i、b_i≥0、b_i≥P_i−Y_iを置き、Σv_i a_i≤baseline under、Σv_i b_i≤baseline overとすれば、二次目的＋線形制約の凸二次計画になる。この分類はアフィン式・二乗・凸関数の上限制約についての[DCPの規則](https://www.cvxpy.org/tutorial/dcp/index.html)に基づく。これはCVXPYや特定solverの導入決定ではなく、Mac/Python3.14.8でのbackend可用性は未確認。

補助変数は不等式を表すだけで、違反を許すslackではない。β=0、a_i=max(Y_i−B_i,0)、b_i=max(B_i−Y_i,0)は可行である。λ=1によりβについて強凸なので、数学上の最適βは一意だが、補助変数まで一意とは限らない。既知可行点があるためsolverのinfeasible結果は、仕様/実装/数値の不整合として扱う。β=0という返値だけで最適性や非ゼロ可行解の不存在を認定しない。

総量をBへ固定する等式は置かない。同じQの重みでL=平均絶対誤差、m=平均符号付き誤差とすればU=(L−m)/2、O=(L+m)/2なので、両側条件はΔL≤−|Δm|に等しい。平均数量の変化は許されるが、その符号付き誤差の変化を上回る絶対誤差の削減が必要になる。これは各窓の量固定やunder/over各行の非増加条件ではない。

四季の制約を共有βへ同時に課すため、条件が衝突して再び補正0になる可能性はある。これは前方式の年間最小alphaとは異なるが、共通表現の制約として停止し得る。soft penaltyは違反と他の損失改善を交換できるため、厳密非増加の代用にならない。分位点目的への変更も行わず、「条件付き平均を目標とした制約・正則化付き推定」と位置づける。14日総量とB比例配分だけから各日平均や潜在需要を識別したとは言わない。

## floor、配分、失敗の区別

学習内でP=max(B+hβ,0)を過小量へ直接代入すると、一般に凸性を失う。例えばY=1、floor前Pが−1,0,1なら過小量は1,1,0で、中央が端点平均を超える。学習内はアフィンPと線形非負制約を用いる。

未知入力への予測規則は、入力支持あり/B>0ならP_future=max(B+hβ,0)、日次p_d=B_d×P_future/Bとする。B=0または特徴不支持はそのままB。未知行へのfloorも日次B比例も、未知のbaseline比リスクを保証しない。休業相当maskの0を維持し、将来ラベルが欠測だから予測を止める処理は加えない。

構造支持不足なら事前規則によるB固定で理由を保存する。非有限解・solver失敗・制約残差未解決はfailureとし、支持不足や最適β=0と混同しない。outerのラベルを見たB差替えは行わない。

## 実装前に固定する数値検証と有限工程

今回は可行性solveも実行していない。次の具体工程は実データfitではなく、solver/backend、スケーリング、終了条件、数値証明を固定する実装契約と人工fixtureの整備である。

1. 既知のβ=0可行点、両側hinge、e=0境界、特徴不支持/B0、floor、店等重みと分母を人工値で照合する。入力境界とcutoff canaryも継承する。
2. solverの版・設定・反復/時間/資源上限と数値許容を成績前に固定する。制約の0という基準は緩和せず、数値誤差の判定と統計上の非劣性marginを混同しない。
3. 返ったβについて元の数量単位でhingeを再計算し、補助変数の値だけでpassとしない。丸め後の保存係数に対してもチェックする。境界・近ゼロは有理数/区間など別算法による符号確認を設計し、判定不能なら未判定/failureとする。結果を見た係数縮小による救済は加えない。
4. primal/dual残差、目的値、dual gapまたは別の最適性証明、solver終了理由を保存する。β=0は制約境界にあり、厳密内点があるとは仮定しない。ゼロ最適の証明・非ゼロ可行性・目的改善可否・数値未判定は別の結論とする。
5. 実データへの可行性監査や一巡を行うなら、返す結論と終了条件を別契約で先に固定する。一仕様の有限工程で終了し、currentQ限定化・制約緩和・Q-MSE追加・別特徴へ結果後に接続しない。

可行方向の一次微分は診断に使えるが、一般の非ゼロ可行性の証明ではない。e_i=B_i−Y_i、z_i=h_i dとすると、over微分はe>0でz、e<0で0、e=0でmax(z,0)。underは符号を逆にした式であり、e=0行を落とさない。Q別MSE制約を将来別途考える場合には一次項0でも二次項正なら任意の正stepで悪化するため、一次条件だけのpassは不可。この拡張・監査は今回候補化/実行しない。
